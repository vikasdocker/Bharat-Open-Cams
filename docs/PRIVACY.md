# Privacy Notice

**Applies to:** the current Bharat Open Cams web and Android starter, as stored in this repository. This notice must be reviewed before a public production launch and updated whenever the implementation or hosting changes.

## Current prototype

- The web directory loads the public catalog file from the same site.
- The prototype does not intentionally set cookies, use analytics, build viewer profiles, or request a viewer's precise location.
- The Android screen currently requests no camera, microphone, contacts, storage, or location permissions.
- If a viewer chooses “Suggest an official source”, the app/site opens GitHub's issue form in the viewer's browser. GitHub then processes that interaction under its own privacy terms.
- If the site is hosted on GitHub Pages, GitHub may process technical request data (such as IP address, user agent, and timestamps) to provide and secure the hosting service.

## Camera source data

Catalog entries describe public sources and their publisher, terms, attribution and verification state. Do not put credentials, private stream URLs, confidential permission correspondence or viewer data in the public catalog.

## Future features

Before adding user accounts, favorites sync, maps, push notifications, analytics, location-aware results, playback proxies or any backend, update this notice to describe actual data collection, purposes, retention, providers, security, user choices and contact/removal mechanisms. Request only the permissions essential to a feature and explain them in context.

## Contact and concerns

Use the repository's Issues area for general project questions. Do not put personal information, credentials or private camera footage into a public issue. Use the repository's private vulnerability reporting feature if available for security concerns.

This notice describes the current prototype and is not legal advice. Obtain qualified review for the intended launch jurisdictions and platform requirements.
